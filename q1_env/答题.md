# 题一 开发环境与工程规范

## 环境搭建

在 Windows 11 上使用 Python 3.13.11，满足题目 Python 3.10 及以上要求。为避免系统依赖与考核代码相互影响，在项目根目录创建独立虚拟环境 `.venv`，通过依赖清单安装运行库。

| 软件或库 | 本次版本 | 用途 |
|---|---|---|
| Python | 3.13.11 | 脚本运行环境 |
| NumPy | 2.5.4 | 数组、坐标与误差计算 |
| OpenCV Python | 5.0.0.93 | 摄像头采集、角点检测、标定与 PnP |
| Matplotlib | 3.11.2 | 误差可视化 |
| PyYAML | 6.0.3 | 配置文件读写依赖 |
| ReportLab | 5.0.1 | 生成矢量棋盘格 PDF |

创建和安装命令（在项目根目录执行）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r q2_calib/requirements.txt
.\.venv\Scripts\python.exe -m pip check
```

2026-10-18 检查结果为 `No broken requirements found.`。摄像头采集、真实图像角点检测、标定和单点 PnP 均已实际运行。环境核验结果见 [environment_check.json](environment_check.json)，依赖版本见 [requirements-lock.txt](../q2_calib/requirements-lock.txt)。

- `q1_env/`：环境检查与本题答题。
