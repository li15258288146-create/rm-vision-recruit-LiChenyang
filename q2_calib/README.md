### 40 cm 粗测预实验

原图：`images/measure/20261018_203840_129832.png`。本人提供测距仪粗测读数 0.40 m，仪器测量基准及瞄准位置尚未核实；打印方格尺寸仍按设计值 20 mm，未实测。

由于纸张外角没有全部清楚入镜，本次使用 54 个棋盘格内角点进行 PnP，目标原点位于棋盘中心。估算距离为 0.397650 m，与粗测读数相差约 2.35 mm，相对差异约 0.59%，重投影 RMS 为 0.7894 px。这些小数是程序计算输出，不表示实测读数具有相同精度。棋盘中心与纸中心按打印版设计相差 5 mm。

该数据用于验证流程，不计作正式 A4 四角测距实验，也不据此宣称毫米级精度。结果和标注图保存在 `results/quick_check_40cm/`。

后续可先使用本人逐组提供的测距仪粗测读数，并明确记录其性质。需拍摄不少于五组、约 0.5～3 m 的 A4 图片，每组四个外角完整可见，分别记录对应照片与实际读数。不能用计划距离替代读数，不能从当前一组数据推算其他组的实验结果。

### 内参与误差概念

内参中的 fx、fy 是像素单位的焦距，cx、cy 是主点坐标。像素横纵尺寸接近、图像没有非等比例缩放时，fx 与 fy 通常接近；这里两者约为 909.8 px。主点不一定严格位于画面几何中心。

重投影误差衡量检测到的角点像素坐标与相机模型投影坐标的差异。本程序报告每个角点二维距离的均方根，单位 px；它衡量模型拟合程度，不等于真实距离误差，也不能单独证明标定正确。板面起伏、角点噪声和相机设置变化都可能影响结果。

## 5. A4 测距

使用平整的 A4 纸外边缘（210×297 mm），竖向放置，并标记纸张物理左上角。建议测量 0.5、1、1.5、2、2.5、3 m，每组拍三张并记录真实距离与卷尺依据。保持相机设置不变，不要临时变焦。

```powershell
.\.venv\Scripts\python.exe q2_calib/capture.py q2_calib/images/measure
.\.venv\Scripts\python.exe q2_calib/measure.py q2_calib/images/measure/你的图片.png --true-distance 1.003
```

真实距离参数单位 m，请填实际读数。按纸张物理方向依次点击 **左上→右上→右下→左下**，R 重选、Enter 确认、Esc 取消。显示缩放自动换算回原图坐标，不改变内参。

脚本使用原图 + 原始内参 + 畸变参数。不要输入去畸变图。输出纸中心空间距离 `norm(tvec)` 和光轴深度 `tvec[2]`，实测应对应前者。用镜头附近明确固定位置作为卷尺基准，并在报告中说明其与实际光心可能存在偏差。

结果追加到 `results/measurements.csv`；每次测量另存唯一命名的标注图与角点 JSON，不覆盖此前点击。重复点击同一张照片只代表标点重复性，不等于独立拍摄的重复实验。

比较不同标定参数时可复用同一图片角点：

```powershell
.\.venv\Scripts\python.exe q2_calib/measure.py q2_calib/images/measure/你的图片.png --true-distance 1.003 --points q2_calib/results/对应的_points.json --camera q2_calib/results/five_images/camera.json --out q2_calib/results/five_images
```

## 6. 实验与报告

- 基本实验：至少五组距离、实测依据、误差表和曲线。
- 发挥：保持纸中心不动，比较正对、30°、60°；比较五张标定图、全正对图、错误方格尺寸。
- 同一批测距图片和角点用于对比不同参数，避免混入点击差异。
- 方格尺度改变主要影响标定外参尺度；不要直接认定正确 A4 尺寸下的后续 PnP 也同比缩放。
- 讨论角点定位、纸张弯曲、标定视角、焦距变化和实测基准等误差。
- 重投影误差单位为 px；测距误差单位为 m。平面四角解算可能存在姿态不稳定，需用实测和重复实验检查。
