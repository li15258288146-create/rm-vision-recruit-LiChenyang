# B 题发挥部分补全方案

目标：完成六项发挥要求并保留可复现证据。

- [x] terrain_advanced.py：有限小孔补全、局部平面坡度及台阶分类，合成坡道/台阶验证；异常物体候选检查与可追溯处理。
- [x] register_map.py：固定米制尺度，以场地障碍轮廓估计 SE(2)，比较旋转候选、输出残差及重叠图；不按参考图修改自建通行格。
- [x] compare_maps.py：相同七组查询在配准自建地图运行两种手写算法，记录不可达原因、长度、碰撞检查及与参考图差异。
- [x] decision_sim.py：按血量、弹量、敌方位置、剩余时间、前哨状态选择状态；通过 A* 移动、视线检查、补给和战斗模型验证，保存轨迹、转移图、视频与日志。
- [x] test_advanced.py：坡面/台阶、变换恢复、优先级/迟滞/资源恢复及碰撞验证。
- [x] 更新报告、AI 记录，完成运行与结果核查。

采用刚性配准而非任意缩放，保留旧结果；采用有限状态机而非行为树便于本题讲解。缺失点云仅进行有界局部插值，不从参考图复制空闲区域。仿真规则是可复现工程场景，不声称官方比赛规则或实车验证。
